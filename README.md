# Overview

This project is a simple Hello World application created using JavaScript. The program displays two messages in the terminal: "Hello World" and "I'm building my skills, one project at a time!"

The purpose of creating this software is to practice basic programming concepts and improve my skills as a software developer. Through this project, I practice using variables, functions, and console output in JavaScript.

This project also helps me become more familiar with Visual Studio Code, Node.js, and the process of developing and running software.


# Development Environment

I used the following tools to develop this software:

- **Visual Studio Code:** A code editor used to write and organize my JavaScript code.
- **Node.js:** A JavaScript runtime environment that allows me to execute JavaScript programs outside a web browser.
- **JavaScript:** The programming language used to create this application.

The program uses a function called `showGreeting()` to display messages in the terminal using `console.log()`.

To run the program, open a terminal in the project folder and execute:

```bash
node hello.js
```
